# 🏥 YRCS Hodeidah HR Management System

نظام إدارة الموارد البشرية لفرع جمعية الهلال الأحمر اليمني - الحديدة

## ✨ المميزات الرئيسية

### 📊 لوحة التحكم (Dashboard)
- إحصائيات شاملة عن الموظفين والحضور والرواتب
- رسوم بيانية تفاعلية
- نظرة عامة على جميع الأقسام
- روابط تلقائية بين الوحدات

### 👥 إدارة الموظفين (Employees)
- إضافة وتعديل بيانات الموظفين
- البحث والتصفية حسب القسم
- عرض بطاقات الموظفين
- تفاصيل شاملة لكل موظف

### 📅 تتبع الحضور (Attendance)
- تسجيل الحضور اليومي
- تتبع التأخير والغياب
- إحصائيات شهرية
- ربط تلقائي مع كشوف الرواتب

### ⏰ إدارة كشوف العمل (Timesheet)
- تسجيل ساعات العمل
- عرض أسبوعي وشهري
- الموافقة على كشوف العمل
- حساب العمل الإضافي تلقائياً

### 💰 كشوف الرواتب (Payslip)
- إنشاء كشوف الرواتب تلقائياً
- حساب الخصومات والعلاوات
- حساب الضرائب
- ربط تلقائي مع الحضور وكشوف العمل
- طباعة كشوف الرواتب

### 📈 التقارير (Reports)
- تقارير تحليلية شاملة
- رسوم بيانية تفاعلية
- مقارنة بين الأقسام
- تصدير التقارير

### 📱 تحويل إلى APK (Build APK)
- تحويل التطبيق إلى تطبيق أندرويد
- تحميل أيقونات التطبيق
- دليل شامل لتحويل PWA إلى APK
- 3 طرق مختلفة للتحويل

- تصميم عصري ومتجاوب

## 🚀 التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - لغة البرمجة
- **Vite** - أداة البناء
- **Tailwind CSS** - إطار عمل CSS
- **PWA** - تطبيق ويب تقدمي
- **Service Worker** - للعمل بدون إنترنت

---

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js 16+
- npm أو yarn

### التثبيت

```bash
# تثبيت المكتبات
npm install

# تشغيل التطبيق في وضع التطوير
npm run dev

# بناء التطبيق للإنتاج
npm run build
```

---

## 📱 تحويل إلى APK

التطبيق هو PWA (Progressive Web App) يمكن تثبيته مباشرة على أندرويد أو تحويله إلى APK.

### التثبيت المباشر (الأسهل)
1. افتح التطبيق في Chrome على أندرويد
2. اضغط القائمة (⋮) → "Add to Home screen"
3. سيتم تثبيته كتطبيق عادي!

### تحويل إلى APK
راجع ملف [APK_GUIDE.md](./APK_GUIDE.md) للتعليمات التفصيلية.

## 🔗 الروابط التلقائية

النظام يدعم الربط التلقائي بين:

1. **الحضور → كشوف الرواتب**
   - أيام الغياب تُخصم تلقائياً من الراتب

2. **كشوف العمل → كشوف الرواتب**
   - الساعات الإضافية تُحسب تلقائياً

3. **كشوف العمل → الحضور**
   - التحقق من تطابق ساعات العمل مع الحضور

## 🎯 الاستخدام

### إضافة موظف جديد
1. اذهب إلى تبويب "Employees"
2. اضغط "Add Employee"
3. املأ البيانات
4. اضغط "Add Employee"

### تسجيل الحضور
1. اذهب إلى تبويب "Attendance"
2. اختر التاريخ
3. اضغط "Mark Attendance"
4. اختر الموظف والحالة
5. احفظ

### إنشاء كشف راتب
1. اذهب إلى تبويب "Payslip"
2. اضغط "Generate Payslip"
3. اختر الموظف والفترة
4. سيتم الحساب تلقائياً
